PINKY PUSSY — SOLICITUDES A DISCORD

Incluye la página de solicitud con fondo, el servidor y el envío de logs a Discord.
Cada solicitud publicada incluye @everyone. Esto notificará a todos los miembros
del canal/servidor que puedan recibir esa mención; úsalo solo si los administradores
del servidor están de acuerdo.

SEGURIDAD IMPORTANTE:
El webhook que pegaste en el chat quedó expuesto. Elimínalo/regénéralo en Discord
y usa el NUEVO webhook. No lo pongas dentro de index.html ni lo compartas.

INSTALACIÓN:
1. Sube estos archivos a un hosting que permita Node.js.
2. Ejecuta: npm install
3. Configura la variable privada DISCORD_WEBHOOK_URL con el webhook nuevo.
   También puedes copiar .env.example a .env y pegarlo allí.
4. Ejecuta: npm start
5. Abre la URL pública del hosting para usar el formulario.

No abras index.html directamente como archivo local: el formulario necesita
el servidor Node.js para enviar la solicitud. Nunca publiques .env.
